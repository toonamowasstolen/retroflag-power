# License Policy

This follows the host-wide default — license choice is not made per
project from scratch, it follows which family a project belongs to — but
it is maintained here as this project's own record rather than a link out
of the repository. If this project's license situation ever changes,
change this file; a clone should never have to go looking elsewhere to
learn its own terms.

## This project

**MIT**, and the repository is **public**.

RetroFlag Power is open source. It is a daemon for hardware other people
own, aimed at a community that has been modding these cases for years —
being able to read it, fork it, and check what it does to your handheld
before running it as root is part of the point, not a concession.

Apache-2.0 was the plausible alternative, since hardware-adjacent projects
sometimes prefer its explicit patent grant. It was not chosen: there is no
patent surface worth the extra ceremony here, and MIT is what this corner
of the retro-handheld community already expects to see.

See [`LICENSE`](LICENSE) for the actual text.

## What that obliges

- Keep the copyright notice intact in redistributions. That is nearly the
  whole of MIT's ask.
- Original assets only. Inspiration from retro gaming culture is welcome;
  copyrighted imagery is not, and no license fixes that.
- Vendored third-party code keeps its own license and its own provenance
  note. This policy covers the project's own work, not code it borrowed.
